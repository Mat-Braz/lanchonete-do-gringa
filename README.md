# Lanchonete do Gringa

Site responsivo em HTML, CSS e JavaScript da Lanchonete do Gringa em Guarani d’Oeste, SP.

## Publicação
GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root).

## Arquivos
- index.html: estrutura e conteúdo
- style.css: estilos responsivos
- script.js: menu no celular
- lanchonete.png: foto do estabelecimento

## Desenvolvimento
Execute `python3 -m http.server 4173` e abra http://localhost:4173.
